# Graphics Programming Practice

A C++ graphics programming learning project focused on implementing rendering
techniques from first principles.

The current renderer is a CPU-based ray tracer. raylib is used for windowing
and displaying the resulting pixels, while the ray tracing implementation is
written directly in C++.

## Features

- Ray-tracer
	- Ray/sphere intersection
	- Per-pixel ray tracing
	- Closest-object intersection
	- Ambient lighting
	- Point lighting
	- Directional lighting
	- Diffuse/specular lighting
	- Shadows and reflection
	- Camera translation and rotation
- Rasterization [In progress]
	- Point-to-point linear interpolation
